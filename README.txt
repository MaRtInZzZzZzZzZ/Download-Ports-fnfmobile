FRAME FUNCTION — SITIO DE DESCARGAS

1. Extraé todo el contenido de este ZIP.
2. Subí index.html, styles.css, app.js, mods.json y la carpeta downloads a la raíz del repositorio GitHub.
3. En GitHub: Settings > Pages > Build and deployment > Deploy from a branch.
4. Elegí la rama main y la carpeta /(root), y guardá.
5. La web aparecerá en https://TU-USUARIO.github.io/frame-function-downloads/

IMPORTANTE SOBRE LOS MODS:
Este paquete contiene el sitio web, pero no incluye los archivos ZIP binarios de los mods.
Para que los botones funcionen, colocá dentro de downloads/ los archivos reales con estos nombres:
- frame-function-mobile-v0.3.2.zip
- note-color-editor-v2.1.4.zip

Si tus archivos tienen otros nombres, modificá las rutas correspondientes en app.js.
